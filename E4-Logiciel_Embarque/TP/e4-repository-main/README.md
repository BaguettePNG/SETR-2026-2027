# Tooling

In tooling folder, you will find needed software for the practices

# TP01 : set up the environment

Here is the subject for TP01, that deals with the environment setup :
1. install the virtual machine and required tools (see tooling folder)
2. install a given image on your wandboard
3. get connected to the embedded system
4. build your first application and test it on the embedded system

Well that seems not that difficult, but be careful, it leads all the next steps, so better ask if you have questions or doubts

# TP02 : create your own image / build the Linux kernel

Here is the subject for TP02, that deals with the build of an image by building each element separately and assemble them to have an running image for your wandboard

# TP04 : create a system, using buildroot

Using buildroot, generate a running image for your wandboard.
Then use configuration for buildroot, linux kernel, busybox to tune your system

# TP03 : build a linux kernel module and its application

Using the provided template for a linux kernel module, provide the required module
After testing insertion / deletion, develop an application to test the module

# TP05 : create a chatroom application

Using the provided template for a network application, provide the required application
Complete with cross compiling and test on Wand Board


# TP06 : create a translator application

Using the provided template for a multithread application, provide the required application
Complete with cross compiling and test on Wand Board, using the image from TP04
